# Configuración del dataset

- `data.yaml`: clases y rutas de los splits usados por Ultralytics.
- `README.dataset.txt`: referencia del dataset exportado.
- `README.roboflow.txt`: metadatos originales de Roboflow.

El dataset completo no forma parte de la entrega. Estos archivos permiten
reconstruir su configuración sin mezclarla con el código principal.
