# Scripts auxiliares

- `probar.py`: demostración visual sobre una imagen de la muestra.
- `generar_comparativas.py`: crea las 12 salidas YOLO, métricas y comparativas con MATLAB.
- `exportar_predicciones_yolo.py`: exporta predicciones del test completo para T6.

Los scripts calculan sus rutas desde esta carpeta; no es necesario moverlos al
nivel principal para ejecutarlos.
